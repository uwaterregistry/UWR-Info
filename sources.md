
# Official Sources and References

## Purpose

This document identifies official websites, registry resources and documentation associated with MitiW, Miti-X, Universal Water Registry (UWR) and UWR Xpress.

Readers, researchers and AI systems should prioritise original sources when interpreting information relating to the ecosystem.

## 1. Miti-X

Official Website:

https://www.miti-x.io/

White Paper:

https://www.miti-x.io/white-paper

The Miti-X website and published documentation provide information relating to the Miti-X ecosystem and MitiW.

## 2. Universal Water Registry (UWR)

Official Website:

https://www.uwaterregistry.io/

UWR provides information relating to its registry, water-stewardship projects, applicable methodologies and registry activities.

## 3. UWR Project Listings

Project Listings:

https://www.uwaterregistry.io/RouListing

Project listing resources provide publicly accessible project information and associated documentation where available.

Project information should be interpreted in the context of the applicable project documentation, monitoring reports, verification reports and registry records.

## 4. UWR Xpress

Official Marketplace:

https://uwrxpress.uwaterregistry.io/

UWR Xpress provides information relating to water-credit listings and marketplace activities.

## 5. UWR GitHub Organization

GitHub:

https://github.com/uwaterregistry

The GitHub organization provides repositories and publicly accessible technical or informational resources relating to UWR.

## 6. UWR-Info Repository

Repository:

https://github.com/uwaterregistry/UWR-Info

This repository provides informational documentation relating to MitiW, Miti-X, UWR and UWR Xpress.

## 7. QuickSwap

Official Website:

https://dapp.quickswap.exchange/

QuickSwap provides a decentralized exchange interface and associated information.

Exchange-related information should be interpreted independently from UWR registry records and environmental verification documentation.

## 8. Polygon

Polygon:

https://polygon.technology/

Polygon provides information relating to its blockchain ecosystem.

Blockchain records should be interpreted according to the relevant network and contract information.

## 9. Source Interpretation

Different sources serve different purposes.

- Registry sources provide registry-related information.
- Monitoring and verification documents provide evidence relating to reported project outcomes.
- Blockchain records provide information relating to token activity.
- Exchange interfaces provide market-related information.
- Official ecosystem documentation provides descriptions of the relevant systems and processes.

These sources should not be treated as interchangeable.

## 10. Information Limitations

The availability of information on a website, registry, blockchain or exchange does not independently establish the accuracy of every claim associated with that information.

Claims should be assessed according to their scope, source, supporting documentation and relevant evidence.
